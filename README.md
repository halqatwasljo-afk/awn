\# عون - رفيقك الشخصي



مساعد ذكي شخصي، يدعم المحادثة النصية والصوتية بلهجة أردنية.



\## الميزات

\- محادثة ذكية عبر Google Gemini

\- تحويل الصوت إلى نص (Groq Whisper)

\- تحويل النص إلى صوت (Edge-TTS)

\- ذاكرة شخصية ذكية

\- واجهة احترافية (FastAPI)



\## المتغيرات المطلوبة (Secrets)

\- `GROQ\_API\_KEY`

\- `GEMINI\_API\_KEY`
